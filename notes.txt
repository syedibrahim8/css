// WHAT IS CSS
CSS = Cascading Style Sheets
CSS is used to style HTML elements

HTML = structure
CSS = design/look/layout

Without CSS, websites look plain and boring.
Example:
HTML says:"This is a heading"
CSS says:"Make it blue, center it, increase size"

// Why CSS is important
CSS helps you to:
Change colors
Change fonts
Control layout
Make websites responsive
Create animations

// How CSSS works (simple idea)
CSS selects an HTML element and applies styles to it.

selector{
    property:value;
}

h1{
    color:red;
    font:size:32px;
}

h1 -> selector
color -> property
red -> value

// 3 Ways to Add CSS

1.Inline CSS (NOT recommended)
<h1 style = "color : red ;" > Hello </h1>

2.Internal CSS
<style>
h1{
    color:aqua;
}
</style>

3.External CSS (Best practice)
<link rel = "stylesheet" href = "style.css">
h1{
    color:green;
}
